# Travel Weave — итерация 1: фундамент (глобус + плетение + таймлайн + бюджет + Firebase)

## Что показало исследование

- **travel-weave** — чистый шаблон Angular 19.1 (standalone, LESS, strict TS), node_modules установлены, git-remote не настроен. Приложение нужно строить с нуля.
- **car-keeper** даёт готовые паттерны для копирования: инициализация Firebase через провайдеры в `app.config.ts` (`provideFirebaseApp/provideAuth/provideFirestore` с `ignoreUndefinedProperties: true`), Auth и Firestore на сигналах, хелпер `runInInjectionContext` для подписок, и `StorageService` на **Supabase Storage** с компрессией фото на canvas (модель `{url, path, createdAt}`, удаление старого файла при замене, пути `cars/{uid}/{carId}/...`). Всё это переносим в travel-weave.
- Remote GitHub обнаружу через `gh` CLI при реализации; если не получится — сделаю локальные коммиты и отдам готовую команду для привязки remote.

## Технические решения

- **Стек**: Angular 19 (уже есть) + `three` + `@types/three` (без Angular Three — сырой Three.js в классе-движке вне Angular-зоны надёжнее и легче), `@angular/fire` + `firebase` v11, `@supabase/supabase-js`, `@angular/pwa`. Анимации UI — CSS/Less-переходы, GSAP не нужен в итерации 1.
- **Глобус**:Three.js сцена — сфера с шейдером день/ночь (текстуры NASA Blue Marble + night lights, скачаем в `public/textures/`, public domain), fresnel-атмосфера, процедурное звёздное поле. Вращение с инерцией, зум, raycast-клики → широта/долгота. Рендер-луп через `NgZone.runOutsideAngular`.
- **Нити**: дуги большого круга (slerp + подъём над поверхностью), разные стили: перелёт — светящаяся дуга, поезд — пунктир, авто — градиент, круиз — волна, пешком — тонкая точечная. Прорисовка анимацией, искры-частицы вдоль нити.
- **Поиск городов**: Open-Meteo Geocoding API (бесплатно, без ключа); обратный геокодинг клика — BigDataCloud free client API (без ключа).
- **Язык UI**: русский. Стиль — «космический атлас»: тёмно-синий фон, бирюза + золото, свечение.

## Модель данных (Firestore)

- `users/{uid}`: email, displayName, settings.currency.
- `trips/{tripId}`: ownerId, title, startDate/endDate, currency, **вложенные массивы** `waypoints[]` (id, name, country, lat, lng, arrival/departure, note, photo: StoredFile, budget/день) и `segments[]` (type: flight/train/car/cruise/walk, price, durationHours), createdAt/updatedAt. Вложенные массивы упрощают drag-reorder (один `updateDoc`).

## Этапы (коммит после каждого, сборка `ng build` обязательна)

1. **Фундамент**: установка зависимостей; `environment.ts` (firebase-конфиг travel-weave + заглушки supabase url/anonKey/bucket); `app.config.ts` по паттерну car-keeper; подъём бюджетов бандла в angular.json; remote + первый коммит.
2. **Core-сервисы**: `models.ts`, `auth.service.ts` (email/пароль + Google, сигналы), `trips.service.ts`, `storage.service.ts` (Supabase, компрессия, как в car-keeper), `geo.ts` (lat/lng↔vec3, slerp, дистанции), `budget.service.ts` (расчёт по дням/категориям, прогноз).
3. **Глобус**: `globe-scene.ts` (движок), `globe.component.ts`, текстуры, атмосфера, звёзды, инерция, зум, fly-to анимации, hover-подсветка.
4. **Плетение**: режим добавления точек (клик + поиск), вспышка и расходящиеся кольца, нити 5 стилей с прорисовкой и искрами, список точек с drag-reorder, карточка точки и карточка сегмента.
5. **Таймлайн**: лента дней под глобусом, узлы-дни, синхронизация клика с fly-to, базовая валидация стыковок.
6. **Бюджет**: панель с разбивкой по дням/категориям, SVG-график, прогноз «~X за N дней».
7. **Auth + сохранение**: экран входа, guard, список/создание поездок, автосохранение в Firestore (debounce), загрузка фото в карточке точки.
8. **PWA + деплой**: service worker + manifest + иконки, `firebase.json` (hosting `dist/travel-weave/browser`, SPA-rewrite), `.firebaserc`, `firestore.rules` (доступ только владельцу), README с инструкцией (Supabase-ключи, деплой), финальный коммит + push.

## Проверка

- `ng build` на каждом этапе, `ng test --watch=false` для unit-тестов сервисов (geo, budget).
- Запуск `ng serve` и сквозная проверка в браузере: рендер глобуса, добавление точек, прорисовка нитей, reorder, таймлайн, расчёт бюджета, вход и сохранение поездки. Фото-загрузка — если к моменту запуска будут Supabase-ключи (иначе фича остаётся с заглушкой и понятным сообщением).
